# 100 Doors Puzzle

This repository contains a simple Python script that solves the classic
"100 doors" puzzle.

In the puzzle, you have 100 closed doors and you toggle doors on each pass:
on the first pass open every door, on the second pass toggle every second
door, and so on until the 100th pass. The doors left open are those whose
numbers are perfect squares.

## Usage

Run the script with Python 3.11 or newer:

```bash
python3 100Doors.py
```

The program prints the list of door numbers that remain open after the final pass.
